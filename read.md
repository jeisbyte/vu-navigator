# Victoria University Tower Navigator

A static web-based campus directory for the VU Market Plaza building.
Helps students and visitors quickly locate any room by floor, name, or number,
complete with walking directions and photographs.

## How to Use

1. Open `index.html` in any modern browser (Chrome, Edge, Firefox).
2. Click a floor button to view rooms on that floor.
3. Use the **Rooms & Directions** page for a full directory:
   - Jump by name using the A–Z index.
   - Select a room number from the dropdown.
   - Scroll through floors to see all rooms with directions.

## Folder Structure

- `index.html` – Floor selector homepage
- `directions.html` – Master directory with A‑Z index, dropdown, and all directions
- `floors/` – Individual floor pages (B2 to Floor 9)
- `css/style.css` – Responsive stylesheet
- `js/script.js` – Lightbox & scroll animations
- `images/` – Room photographs and logo

## Requirements

- No server needed; runs entirely from your local machine.
- Any modern web browser.
